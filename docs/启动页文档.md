# 启动页设计思想

## 定位

启动页是一键启动工作环境的主入口，收录并快速启动网页、本地文件夹、可运行程序、图片、音乐、视频等常用资源。

## 设计理念：两种工作状态

- **常态（编辑态）**：完整操作能力——管理菜单、卡片、拖拽排序、增删改。
- **紧凑模式（浏览/选择态）**：隐藏一切编辑功能，仅保留二级菜单图标列用于快速切换，提供一个稳定只读的工作状态。

设计动机：紧凑模式的核心不只是「省空间」，而是「切换工作状态」。让日常高频使用（快速选择）不被编辑控件打扰，编辑与使用互不干扰。

## 交互约定

- Tab 双向切换两种状态，Esc 单向退出紧凑模式；焦点在输入框/文本域/下拉框时不触发，避免误切。
- 状态跨会话持久化，重启后恢复上次模式。

## 菜单与卡片

- 菜单可拖拽排序，二级菜单可跨一级菜单移动，层级深度不变；卡片可跨二级菜单拖拽，一级菜单只做分组不管理卡片。
- 网页卡片保存图标时绑定域名，之后添加同域名网页自动复用，可在图标库-网页图标中修改。
- 菜单左侧图标可点击自定义。

## 壁纸

- 设置中可切换图片/纯色壁纸。
- 全局壁纸路径已设置时，新建工作空间默认使用全局空间。
