# 图标库页设计思想

## 定位

集中管理多维工具箱的全部图标，供启动页的卡片与菜单按需引用。

## 设计理念：集中管理与引用

图标统一入库、集中管理，卡片和菜单通过「图标值」引用而非复制——改一处、处处生效，避免同一图标散落多处、重复维护。

## 四类图标设计

| 类别 | 说明 | 添加方式 |
|------|------|----------|
| FA 图标 | Font Awesome 6.7.2 图标 | 输入 FA 类名 |
| Emoji | 表情符号 | 输入 Emoji 字符 |
| 全局图标 | 用户上传的图片 | 本地图片上传 |
| 网页图标 | URL 下载的图标 | 输入 URL 下载，可绑定域名 |

网页图标保存时可绑定域名：启动页添加同域名网页时自动复用该图标，减少重复设置。

## 分组与操作

- 每类初始有一个默认分组，可扩展分组；分组可展开/折叠，状态会被记住。
- 搜索：按图标名或分组名过滤。
- 快捷键 T：显示/隐藏分组名称，便于快速定位。
- 每个类别可设置背景颜色与透明背景。
