# 开发指南

## 技术栈

- Vue 3 + TypeScript + Pinia
- Electron 41
- Vite 6
- Font Awesome 6.7
- SortableJS

## 环境要求

- Node.js ^20.19.0 || >=22.12.0
- pnpm

## 配置与运行

```bash
# 安装依赖
pnpm install

# 开发模式（前端）
pnpm dev

# 开发模式（Electron）
pnpm dev:electron

# 类型检查
pnpm type-check

# 代码格式化
pnpm format

# 代码检查
pnpm lint
```

## 打包

```bash
# 打包为免安装版（win-unpacked 目录）
pnpm build:dir

# 打包为安装包（NSIS 安装程序）
pnpm build:installer
```

## 启动命令

```bash
pnpm run dev:electron
```

## 快捷键

### 全局快捷键

| 按键 | 功能 |
|------|------|
| F1 | 打开当前页面手册 |
| Home | 返回首页 |
| 1 | 切换到启动页 |
| 2 | 切换到图标库 |
| 3 | 切换到获取路径页 |
| Ctrl+1 | 新窗口打开启动页 |
| Ctrl+2 | 新窗口打开图标库 |
| Ctrl+3 | 新窗口打开获取路径页 |

### 页面快捷键

| 按键 | 功能 | 适用范围 |
|------|------|---------|
| F2 | 重命名选中菜单 | 启动页（常态） |
| Ctrl+F | 搜索 | 启动页/图标库 |
| Tab | 切换紧凑模式 | 启动页/图标库 |
| ESC | 退出紧凑模式 | 启动页/图标库 |
| T | 展开/折叠导航条 | 图标库 |
| Q/W/E | 切换栏可见性/重置布局 | 获取路径页 |
