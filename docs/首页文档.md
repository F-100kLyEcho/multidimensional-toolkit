# 首页设计思想

## 定位

首页是其它模块的入口，管理全局的用户数据位置（工作空间）。

## 核心设计：工作空间

工作空间是各模块数据（启动页、图标库、获取路径等）的**物理隔离单元**：每个工作空间对应磁盘上一个目录，切换工作空间即切换整套模块数据。同一套软件、多份可独立使用与备份的数据环境，是本项目的核心构思。

- **默认工作空间**：首次安装自动创建"我的工作空间"，位于系统盘应用数据目录下。
- **重命名**：双击名称进入编辑，回车提交、Esc 取消。
- **打开**：在系统文件管理器中打开该工作空间目录。
- **复制**：递归复制整个工作空间到新路径，用于迁移或备份；目标路径需为空目录或不存在，新名称不可与已有重复。复制时跳过被占用的文件（如 Cookies、Cache 等运行时临时文件），这些会在新工作空间中按需自动重建，不影响使用。复制仅新增工作空间条目，不切换当前工作空间。
- **删除**：物理删除工作空间目录及全部内容；至少保留一个工作空间，仅剩一个时删除按钮禁用。

## 迁移到其它盘

因至少保留一个工作空间，要清理 C 盘 / 搬迁至其它盘的步骤：
1. 新建一个指向其它盘的工作空间。
2. 用「复制」将 C 盘工作空间的内容递归复制过去。
3. 删除 C 盘的旧工作空间。
